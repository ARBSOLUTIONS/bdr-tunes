# bdr-tunes

Validated Bounty Drag Racing tunes found by BDR Crew Chief, read by the BDR Setup Loader.

- `index.json`: list of all tunes (class, car, engine, tire, conditions, drivetrain, ET).
- `tunes/<class>/<car__adder__engine__tire>/<track>_<length>_<prep>_DA<bucket>_<mode>[_drivetrain].json`

Updated automatically after each successful search. Download the app from Releases.
